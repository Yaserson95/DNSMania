# DNS Mania

Настольное приложение для Windows, упрощающее управление DNS-сервером Windows Server:
зоны, области (zone scopes), ресурсные записи, клиентские подсети и политики разрешения
запросов. Интерфейс в стиле `dnsmgmt.msc`, но с журналом отложенного применения изменений.

> На машине администратора **не нужен RSAT**: все команды выполняются на целевом сервере
> через PowerShell-ремоутинг (WinRM, `Invoke-Command`).

## Возможности

- **Зоны** — прямой просмотр (с областями), обратный просмотр (записи без уровней
  областей), зоны пересылки (forwarders): просмотр, создание, изменение, удаление.
- **Ресурсные записи** — плоский список «одна запись — одна строка», как их отдаёт
  `Get-DnsServerResourceRecord`. Правка A, AAAA, CNAME, NS, MX, TXT, PTR, SRV
  (правка = удалить старую запись с её параметрами и добавить новую); SOA — просмотр.
- **Области (zone scopes)** — список и свойства области, записи внутри области.
- **Клиентские подсети** (`Get-DnsServerClientSubnet`) и **политики разрешения запросов**
  (`Get-DnsServerQueryResolutionPolicy`) с настроенными весами областей.
- **Журнал изменений** — правки не выполняются сразу, а копятся в журнале и применяются
  кнопкой «Сохранить» (Ctrl+S). Ctrl+Z — отмена, Ctrl+Y — возврат; перед применением
  показывается список накопленных действий.
- **Кэш** — данные кэшируются в файлах и обновляются при запуске: дерево открывается быстро,
  офлайн-просмотр доступен по кэшу.
- **Несколько серверов** с быстрым переключением; учётные данные по каждому серверу
  хранятся через DPAPI текущего пользователя.
- Запуск стандартного консольного оснащения `dnsmgmt.msc` прямо из меню «Файл».
- Без консольного окна, со своей иконкой.

## Системные требования

- Windows 10/11 или Windows Server на машине администратора (приложение x64).
- Целевой DNS-сервер: Windows Server 2012 R2 или новее с установленным модулем **DnsServer**.
- Доступ по **WinRM** (режим по умолчанию) либо локальный PowerShell с `-ComputerName`
  (тогда на машине администратора требуется RSAT DNS-Tools).

## Подключение

1. **PowerShell-ремоутинг (WinRM)** — режим по умолчанию. Используется интегрированная
   аутентификация (Kerberos в домене, NTLM вне домена), RSAT на машине администратора
   не нужен.
2. **Локальный PowerShell (`-ComputerName`)** — если на машине администратора установлен
   RSAT DNS-Tools: команды выполняются локально и обращаются к серверу по имени.

Если сервер указывается по IP-адресу вне домена, может потребоваться TrustedHosts:

```powershell
winrm set winrm/config/client '@{TrustedHosts="10.21.0.2"}'
```

Логин и пароль для сервера задаются в диалоге подключения; пароль хранится в DPAPI
текущего пользователя и не покидает машину в открытом виде.

## Установка

Запустите `DNS Mania 1.0.msi` из раздела **Releases**. Установщик собран WiX Toolset v3;
обновление поверх предыдущей версии проходит автоматически (Major Upgrade).

## Сборка из исходников

Требуется Qt 6 (проверено на 6.10.3 + MinGW 13.1; подойдёт и MSVC), CMake ≥ 3.16
и компилятор с поддержкой C++17.

```bat
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Результат — `build\DNSMania.exe`.

### Сборка MSI-установщика

Нужен WiX Toolset v3 (проверено 3.14.1) и Python 3:

```bat
set WIX=D:\tools\wix314
set QT_BIN=D:\Qt\6.10.3\mingw_64\bin
python packaging\make_installer.py
```

Скрипт скопирует `DNSMania.exe`, развернёт Qt-зависимости через `windeployqt`
и соберёт `dist\DNS Mania 1.0.msi`.

## Как это устроено

- **`src/core`** — работа с сервером. `PsClient` запускает `powershell.exe` (без консоли),
  выполняет `Invoke-Command`/локальные cmdlet и принимает результат как JSON
  (`ConvertTo-Json -Depth 25`); `ZoneService`, `ZoneScopeService`, `RecordService`,
  `SubnetService`, `PolicyService` — сущности DNS; `Journal` — отложенные действия;
  `SecureStore` — пароли через DPAPI; `ServerStore` — список серверов в реестре (HKCU);
  `Log` — журнал работы.
- **`src/ui`** — главное окно (дерево объектов + таблицы в стиле `dnsmgmt.msc`)
  и диалоги сущностей.
- `RecordData` приходит с сервера как CimInstance — значения извлекаются
  из `RecordData.CimInstanceProperties` во всех формах сериализации
  (см. `Json::recordDataStr` в `src/core/JsonUtil.cpp`).
- Список серверов: `HKCU\Software\DNS Mania\DNS Mania\servers`.
- Лог: `%LOCALAPPDATA%\DNS Mania\DNS Mania\dnsmania.log`.

## Примеры вывода сервера

Файлы `*_example.json` в корне репозитория — реальные примеры вывода cmdlet
(`Get-DnsServerZone`, `Get-DnsServerResourceRecord`, `Get-DnsServerZoneScope`,
`Get-DnsServerClientSubnet`, `Get-DnsServerQueryResolutionPolicy`) в формате
`ConvertTo-Json`. По ним написан и проверен разбор JSON в приложении.

## Ограничения

- Запись SOA редактируется только на самом сервере (например, через `dnsmgmt.msc`
  или `Set-DnsServerPrimaryZone`); в приложении она доступна для просмотра.
- Интерфейс пока только на русском языке.
