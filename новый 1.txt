1) Меню:
dc01    <--- (справа список: зоны, подсети. При нажатии на пункт мы в него проваливаемся) 
    Зоны  <--- (справа список зон. При нажатии на пункт мы в него проваливаемся) 
        company.lan <--- (справа список с пунктами: узлы, области, правила. При нажатии на пункт мы в него проваливаемся) 
            Узлы    <--- (справа таблица узлов со столбцами по свойствам, окно с содержимым зоны можно убрать) 
                srv01    <--- Обычный узел (не разворачивается, справа отображается свойства узла в виде таблицы с 2мя столбцами ключ - значение)
                srv02    <--- Узел с поддоменом (справа отображается таблица вложенных узлов)
                    @    <--- Обычный узел
                    adm    <--- Обычный узел
            Области    <--- Команда: Get-DnsServerZoneScope -ZoneName "company.lan" (не разворачивается, справа таблица с областями со столбцами по свойствам)
            Правила    <--- Команда: Get-DnsServerQueryResolutionPolicy -ZoneName "company.lan" | Format-List * (не разворачивается, справа таблица с правилами со столбцами по свойствам)
    Подсети    <---- Команда: Get-DnsServerClientSubnet (не разворачивается, справа таблица с подетями со столбцами по свойствам)

2) Так же можно убрать панель с кнопками под меню, можно вместо неё вынести панель из правой части и менять в соответствии с типом выбранного элемента дерева
 Выявлено несколько типов элементов дерева:
	1. Сервер
	2. Папка "Зоны"
	3. Папка "Подсети"
	4. Зона
	5. Папка "Узлы"
	6. Папка "Области"
	7. Папка "Правила"
	8. Узел
	9. Узел с поддоменами (узел с узлами)

3) Само приложение должно выглядеть примерно как проводник виндовс (слева дерево навигации, справа рабочая область)
